# Задачи в Пульте и TASKS.md

Два места, один список. `~/fir-tech/TASKS.md` остаётся файлом, который читают сессии Claude.
Живая копия лежит в панели (`$DATA_DIR/tasks.json`): в ней владелец ставит галочки, меняет
статус, срок и приоритет. Скрипты переносят задачи между ними, сами они не запускаются.

## Когда что запускать

- Сессии поправили `TASKS.md`: выполнить импорт.
- Вы правили задачи в панели: выполнить экспорт, чтобы файл увидели сессии.

Из корня репозитория (путь к файлу по умолчанию `~/fir-tech/TASKS.md`, можно передать первым
аргументом или в `TASKS_MD`; `DATA_DIR` тот же, что у сайта):

```
DATA_DIR=./data node scripts/tasks-import.mjs
DATA_DIR=./data node scripts/tasks-export.mjs [--force]
```

## Что делает импорт

Разделы: `Fir Tech` -> firtech, `Vibely` -> vibely, `Инструменты на Mac` -> tools, остальные
пропускаются. Подпись над задачами задаёт статус и приоритет: «Ждут решения владельца» и «Нужен
вход владельца» дают `blocked`, «Идеи на потом» дают `low`, «Instagram...» переносит задачи в
проект instagram (дата в скобках станет сроком). Первая строка задачи это название, строки с
отступом это заметка. `[x] ... (дата)` это выполненная задача с этой датой.

Импорт можно запускать сколько угодно раз: задача, которая уже есть (по названию или по прошлой
синхронизации), не дублируется и не перезаписывается. Единственное изменение: галочка в файле
закрывает задачу в панели. Правки из панели (приоритет, срок, заметка) импорт не трогает.

## Что делает экспорт

Меняет только строки задач: галочки (с датой закрытия), названия, заметки. Заголовки и обычный
текст остаются, неизменённые задачи не переписываются. Удалённые в панели задачи убираются из
файла, новые добавляются после последней задачи раздела под подписью «Из панели:» («Ждут решения
владельца:» для заблокированных, «Идеи на потом:» для низкого приоритета). Срок и приоритет в файл
не пишутся, они живут только в панели.

Если `TASKS.md` изменили после последней синхронизации, экспорт отказывается работать и просит
сначала импорт, чтобы ничего не потерять. `--force` перезаписывает файл всё равно. Состояние
синхронизации (хеш файла и соответствие строк задачам) лежит в `$DATA_DIR/tasks-md-state.json`.

## Осторожно: запуск при работающем сайте

Импорт и экспорт запускаются отдельным процессом Node и пишут `tasks.json` мимо очереди записи сайта. Если в эту же долю секунды задачу правят в панели или через Echo, правка может потеряться. Запускайте скрипты, когда вы сами не правите задачи в панели (занимает доли секунды), либо при остановленном PM2.
